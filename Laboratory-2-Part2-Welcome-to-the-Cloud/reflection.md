# Reflection

This laboratory helped me become familiar with using a cloud-based Linux environment and basic Linux commands. I learned how to create and manage users, navigate directories, create Markdown files, gather system information, and organize files for a cloud computing portfolio.

Working with KillerCoda gave me practical experience using a Linux environment without needing to install Linux directly on my computer. I also learned how important it is to document my work and organize my files properly.

Creating the GitHub portfolio helped me understand how version control and online repositories can be used to store and present project files. Overall, this laboratory gave me a better understanding of Linux, cloud-based environments, documentation, and GitHub.
