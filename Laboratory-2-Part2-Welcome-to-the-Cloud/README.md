# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory introduces the fundamentals of working with a cloud-based Linux environment. The mission focuses on accessing a Linux playground through KillerCoda, creating and managing a Linux user account, exploring the system environment, organizing files and directories, and creating a professional GitHub portfolio for documenting cloud computing activities.

## Objectives

* Access and use a cloud-based Linux environment through KillerCoda.
* Create and configure a Linux user account with a home directory, Bash shell, and sudo privileges.
* Identify basic Linux system information.
* Navigate the Linux file system and create directories and Markdown files.
* Organize laboratory work into a structured GitHub repository.
* Document activities and maintain evidence through screenshots.

## Activities Performed

1. Launched an Ubuntu Linux environment using KillerCoda.
2. Created and configured a Linux user account with Bash, a home directory, and sudo privileges.
3. Logged in to the newly created Linux user account.
4. Recorded the current username, working directory, and hostname.
5. Investigated the Linux distribution, kernel version, CPU information, total memory, and available disk space.
6. Created the `Notes`, `Reports`, and `Screenshots` directories.
7. Created the `about-me.md` and `system-information.md` Markdown files.
8. Created a public GitHub repository for the Cloud Computing course.
9. Organized the laboratory files into the required repository structure.

## Linux Commands Used

The following Linux commands were used during this laboratory:

* `whoami` – displays the current username.
* `pwd` – displays the current working directory.
* `hostname` – displays the hostname.
* `useradd` – creates a new Linux user.
* `passwd` – sets or changes a user's password.
* `usermod` – modifies user account settings and group membership.
* `su` – switches to another user account.
* `cat` – displays the contents of a file.
* `mkdir` – creates directories.
* `cd` – changes the current directory.
* `ls` – lists files and directories.
* `cp` – copies files and directories.
* `nano` – creates and edits text files.
* `find` – searches for files and directories.
* `uname` – displays system and kernel information.
* `lscpu` – displays CPU information.
* `free` – displays memory usage information.
* `df` – displays disk space information.

I also learned how to write and organize documentation using Markdown and structure laboratory activities in a GitHub repository.
